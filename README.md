# Portfolio

Personal portfolio for a web designer and full-stack developer, built with Next.js (App Router) and TypeScript.

## Edit your details

Everything personal is in `lib/site.ts`: name, email, booking link, work, services, prices and FAQ.
Add a finished project by putting its screenshots in `public/work/` and adding an entry to `work`.

## Run it

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import on Vercel.
